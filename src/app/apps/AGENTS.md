# Webwidget work

Before creating, changing, reviewing, or testing a widget here, read [the MathBoard Web Widget Design Guidelines](../../../docs/webwidget-Design-Guidelines.md) in full and follow the repository-root [AGENTS.md](../../../AGENTS.md), including its teacher clarifications about scoring and completion. These requirements also apply to shared widget code used by these routes.

Keep the guidelines in the single committed `docs/webwidget-Design-Guidelines.md` copy rather than duplicating them in individual widget folders. Record widget changes, validation, deployment status, unfinished work, and MathBoard restoration/mirroring changes in `docs/ai-handoff.md`.
