## Scoring and work
- All 16 problems open immediately; Previous/Next and numbered navigation never require completion. Review all answers is always available.
- Every checked-correct problem starts at 1 point. Each unique requested hint costs 0.2; with all three hints it earns 0.5, not 0.4. Unchecked, changed and incorrect answers earn 0 until checked correct. Unlimited final-answer checks have no deduction. Hint/check counts persist when answers change. Checks are not accumulated into points, so repeat checking cannot farm credit.
- Both individual and review inputs remain editable after success. Changes invalidate the prior check and any old completion record. Review provides per-answer Check and Check all entered answers. The keypad targets the focused review row. Checks/hints and current earned credit appear per problem. Final record lists all 16 answers, statuses, hints, checks and credits plus aggregate totals.
- Reference graph points are optional reading aids, only at integer ordered pairs on the given line; pinned labels use the existing collision-avoidance helper. On Problem 16, Read blue line and Plot my line separate reading from drawing. Two student-selected integer points and Draw my line are checked together with the equation. Changes to a checked graph require a fresh check.
- Explicit two-item submission checklist appears in reflection, final record screen and local image: paper worksheet with work, plus the named online record with both required reflections. No work-photo upload is implemented or implied. Students submit manually.

## Exact-place saves
Stop & save is available on problem, editable review, reflection and final-image screens. New local SaveWorksheet dialog offers a downloadable `.json` progress file and backup code. Because the snapshot includes arbitrary drafts for all 16 questions, the code is intentionally longer than streak-only checkpoints; the file is recommended. The code includes version, initials/hour identity check and checksum, but no full name. It is a convenience checkpoint, not secure authentication.

L4P1 stores all answers, hint/check counts, checked-answer snapshots, graph selections/mode/drawing flag, last-check times, screen, active problem, scroll position, language, completion time and both reflection ratings. Saved final images are regenerated locally from those ratings/data rather than embedding a PNG in a code. Keep the fixed problem set and version stable after release. Resume-file loading validates shape, limits and identity. Nothing is persisted in browser storage or uploaded. There is a before-unload reminder, but students must save a file/code themselves.

Shared CompletionFlow gained optional onSave, submissionInstructions and autoCreate props. Existing widgets keep their default behavior. Read-only MathBoard views cannot save/navigate; no new native bridge was added. Spanish whole-page/tap-English support is included for this worksheet.
