# Standalone 2048

Route `/apps/2048`, linked from Practice apps. Uses Gabriele Cirulli's MIT-licensed original engine at commit `478b6ec346e3787f589e4af751378d06ded4cbbc`. The unchanged grid, tile, game manager, and HTML actuator files, plus full license text, are vendored under `public/games/2048`. SOURCE.json records the exact source revision and SHA-256 hashes. The page provides visible author/source/license credit, including the original game's 1024/Threes acknowledgments.

MacIntodd additions: responsive HTML/CSS, modern pointer swipes, keyboard/onscreen arrows, and a memory-only storage adapter. No ads, trackers, CDN dependencies, names, or server score collection. Best score survives New game in the same page but resets on reload. The existing MathBoard intermission is unchanged.

The isolated full-viewport iframe shows a square board beside instructions and controls on landscape iPads. Smaller phones stack the layout. Board gestures capture pointers and suppress scrolling; the rest of a narrow page scrolls normally. Reduced-motion preferences remove movement/pop animations.

Validation: `node scripts/test-2048.mjs` verifies original-source hashes, all directions, merge-once behavior, score updates, no-op spawn behavior, victory/continuation, game-over detection, and memory-only best score. Normal lint/build/typecheck/content and HTTP route/material checks apply. Native browser preview was unavailable during this task; interactive swipe/render verification remains unconfirmed.
