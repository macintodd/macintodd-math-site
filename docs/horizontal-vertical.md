# Horizontal or Vertical? One-Minute Slope Sprint

Public route: `/apps/horizontal-vertical`, tagged Algebra 2 and Precalculus in Linear graphs and equations. Two-choice questions connect graphs, equation orientation, constant-coordinate equations, zero slope, undefined slope and equations requiring a single inverse operation. Each shuffled twelve-question deck covers every template. Graph lines include both axes themselves and nonzero intercepts; slopes remain zero or undefined. Undefined is never described as infinite slope.

The memory key appears before the clock starts. A single 60-second wall-clock deadline governs the whole round, including feedback; backgrounding does not pause it. Each correct answer earns ten points, misses deduct nothing. A ref locks duplicate answer events before React renders; event-time checks reject late submissions even before the countdown interval ticks. Correct answers trigger a star and green border, then advance after 750ms. Incorrect answers reveal the correct choice and a rise/run cue for 2600ms. Students can advance sooner with Next question. No answer is required for an unfinished question at the deadline.

Final totals include raw points (not a grade out of ten), correct/answered, accuracy and best streak. Missed questions can be reviewed without a timer. Two required five-star reflection questions precede local PNG generation, with identity/date/skill/results/ratings on the scorecard. Native image actions offer sharing/saving where supported. A new minute clears the previous round and reflections; new student also clears identity. No server submissions or browser persistence. Spanish is provided locally, with whole-widget and per-text controls. No resume code is offered for a continuous one-minute round.

Layout uses two columns for graph/equation and two large answer buttons with reserved feedback space, compact landscape styling, phone stacking and reduced-motion fallback. No browser/iPad visual test was available during this update; generation and actual component event paths are exercised by the test harness.

Run `node --experimental-strip-types scripts/test-horizontal-vertical.mjs` for 12,000 generated questions, equation simplification, key correctness, score/accuracy, duplicate clicks, auto/manual advance, exact-deadline rejection, reflections/export and identity reset. Required content/type/lint/build checks also apply.
