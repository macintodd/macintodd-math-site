# Graph the Line: Mixed Practice

/apps/graph-mixed combines the existing graphing methods without changing the three individual apps. A shuffled deck supplies one intercept task, one standard-to-slope-intercept conversion, one slope/y-intercept identification task, and one open-ended task per four problems. Deck boundaries avoid repeating the same task. Equation generators retain countable slopes and prevent three consecutive equal slopes. Standard-form equations have integer x- and y-intercepts with A and B dividing C.

- Intercepts: enter both ordered pairs and graph using those intercepts.
- Conversion: standard form is given; enter m and b in slope-intercept form, then graph with any two correct points.
- Slope/intercept: slope-intercept form is given; state the y-intercept as an ordered pair and the slope as signed rise/run, then graph. This task uses four separate numeric fields and an in-app keypad. Equivalent fractions are accepted; a zero run and a nonzero x-coordinate for the y-intercept are rejected.
- Open-ended: standard or slope-intercept form is given. The prompt is only “Graph the equation.” There are no intermediate answer fields or mandated method; any two distinct points on the line are accepted.

The teacher's phrase “put it standard form” was interpreted as rewriting standard form into slope-intercept form, matching the existing conversion app explicitly named in the request.

All problems have an always-available scratch/graph toggle. Both surfaces remain mounted when hidden, preserving ink, plotted points and drawn lines. Next equation resets the scratch pad. Touch capture, animated line drawing, arrows and correct-answer rewards use the existing components. Missing required entries prompt completion without consuming a scored attempt. A completed check is scored once; incorrect answers reveal the correct graph and applicable worked corrections, followed by the next equation.

Names and class hours stay visible. All state is memory-only. Goals match the individual graphing apps: ten correct and a best streak of six for full credit, with one point deducted for each missing streak step. After ten correct students can submit or continue. The named result page and local PNG include per-task correct/checked totals and completion date, for manual Classroom upload.

Tests cover 240 balanced problems under adversarial constant randomness, 400 method/graph correctness cases, all required/wrong/missing entry rules, open-ended equation-form variation, and actual component events across eleven scored problems including a miss. The flow suite covers scratch/graph switching, completion, per-mode results, named PNG export and new-student reset. Build, types, lint and content checks also pass.
