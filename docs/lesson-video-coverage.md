# Lesson video coverage review — October 26, 2026

Compared published lesson goals, skill headings, problem groups, and the prior PDF selection reviews with the current video topics. The teacher identified missing rate-of-change coverage in Precalculus 1.3. Supplementary clips are chosen by missing topic, not an arbitrary minimum number of videos. Existing coordinate, one-step, basic-inequality, and absolute-value lessons retain their useful videos. The test-review page intentionally links students back to lesson videos instead of embedding another lecture.

Official YouTube metadata verified video availability, title, and channel. Topic decisions use publisher titles/descriptions and the teacher's handouts; this is a topic-coverage review, not a claim that every minute of every video was watched or that a video reproduces every worksheet problem. Mathispower4u's own symmetry page explicitly describes graphical and algebraic tests about the x-axis, y-axis, and origin. Its inequality application was found on the instructor's publisher page.

## Main gaps addressed

- Precalculus 1.2: plotting points, intercepts, algebraic/graphical symmetry, and circle equations replace an overly narrow slope-intercept introduction.
- Precalculus 1.3: slope as rate of change is now video 2; point-slope, parallel/perpendicular lines, and interpreting a linear model have separate clips. Calculator help remains last.
- Factoring packet: add GCF, grouping, nonmonic trinomials, and special products beyond the original monic-trinomial clip.
- Function notation / expression substitution: add evaluation practice and difference quotients; replace the misplaced factoring video on the substitution page. Algebra 2's function follow-up inherits the additional evaluation video.
- Precalculus 1.4: add domains of rational/radical functions and difference quotients beyond introductory function/domain definitions.
- Precalculus 1.5A: add finding zeros, factoring support, and relative extrema. Preserve graph behavior, domain/range, and calculator help.
- Precalculus 1.5B: add rate of change from formulas and linear rate/context examples beyond the existing graph example.
- Algebra 2: add fraction/parenthesis/multistep equation practice, fractional compound inequalities, an inequality profit application, and explicit slope/rate-of-change connections.
- Review pages: fill missing midpoint, symmetry, circle, line-equation, zeros, extrema, and difference-quotient topics.
