## Parallel practice after P4

A correct P4 equation opens **I’m ready to Practice** with a prompt to show the teacher. Starting practice seeds a new set of problems for the session. Every practice answer has an integer y-intercept. Graph problems also have a second integer point visible on the grid.

1. **Graph and check** requires three in a row. Students drag a line or tap its second point, check the sketch, check each slope, then check the equation.
2. **Build point-slope form** requires two in a row. Students check each slope, place the three values, then check the equation.
3. **Independent practice** requires two in a row. The left workspace shows the point-slope formula, scratch paper, and the final answer field. The keypad stays beside the workspace.
4. **Standard form** requires two in a row without hints. The given equation is written as Ax + By = C. Hints reveal the conversion steps one at a time.

A checked mistake resets the current practice streak. An incomplete entry or notation reminder follows the existing unscored reminder flow. Students finish the correction and advance to a fresh problem. Using any standard-form hint also resets that streak. The parallel practice seed, position, and streak progress mirror to the display through the existing student snapshot.
