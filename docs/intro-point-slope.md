# Intro to Point-Slope Form

/apps/intro-point-slope is a separate graph-free introduction for Algebra 2 and Precalculus. The request mentioned both two points and a supplied point/slope; this version follows the detailed supplied-point-and-slope workflow, communicated before implementation. The existing cropped-graph point-slope app is unchanged.

Students enter name/hour (2,3,4,6,7,8). A generated slope and one ordered pair are shown as three draggable quantities. Given x values include both signs and are multiples of the slope denominator so coordinates, the distributed constant and intercept stay integral. Fractional slopes use proper LaTeX. The general formula appears above the three destination boxes. The subtraction signs belong to the template; coordinate signs remain on the tokens.

Touch dragging uses Pointer Events, pointer capture, a non-interactive drag ghost and document.elementFromPoint at release. No HTML native drag-and-drop API is required. Only source chips suppress scrolling. Pointer cancellation clears the ghost without changing placements. As an accessible alternative, students tap/keyboard-activate a source and then a destination. A quantity moves rather than being duplicated; replacing a filled box returns the previous quantity to the source pool. Tap a box with no source selected to clear it. Numerically equivalent placements are accepted when given values happen to coincide.

Check placement unlocks distribution. Check distribution unlocks a complete final equation with x/y/= keys and numeric/fraction keys. Prior validated work remains visible. Intermediate mistakes permit retries and break the first-try streak; a second wrong final equation reveals the steps and ends that problem. All text-entry arithmetic is checked with the existing safe linear-expression parser; no eval. Optional scratch space is memory-only, preserved between steps and reset per problem.

Scoring follows the point-slope app: ten correct plus best first-try streak five for full credit; retry success earns a star without extending the streak. Submission is available after ten correct or a best streak of five. The name stays visible on each screen; named results/PNG include score, checks, streak and date. Nothing is sent or stored, and new-student reset clears everything.

Tests: 600 signed problems, token moves, numerical placement validation, distribution, equations, LaTeX and repeat prevention. Actual component events cover drag/drop/cancel, tap placement, wrong placement, all step gates/retries, keypad y=, grading, named PNG and reset. Catalog tests cover the sixteenth activity card. Build/types/lint/content checks are required. Browser automation is unavailable; iPad visual and actual touch confirmation remains outstanding.

Success splash revision: after a correct final equation, a native modal dialog opens with the student's name/hour and a dynamic “You did it” sentence containing the given point and slope. The sequenced graph plots the given point, flashes the intercept term and plots the intercept, flashes the slope, counts signed horizontal/vertical unit steps, draws the intercept-to-point segment, places a scoring star exactly on the given point, then extends the line. The geometry preserves both signs and equal axis scales. Replay remounts the animation only and cannot award another star. Review/Escape returns to the completed work; Next problem starts a fresh problem. Reduced motion displays the full static solution. Completed green equations are larger, including landscape overrides; backspace, minus and open-parenthesis keys use explicit large symbol sizing.

Added tests: 600 unit-step paths ending exactly at the given point, splash modal/replay/review/next/Escape events, strict displayed LaTeX, and integration with the existing score/export flow. Actual iPad animation timing and visual fit remain unverified because browser automation is unavailable.

Completion/reflection revision: finishing practice opens a congratulations slide with instructions to answer the next slide's questions, screenshot the named/dated score and answers, and turn it in through Classroom. A Finish & reflect action is also available from the success splash once normal submission eligibility is met. The next slide includes final score, correct/checked totals, step checks, current/best streaks, stars, name/hour and a completion timestamp frozen when practice finishes.

Two five-star native radio scales collect self-reflection: confidence in finding slope-intercept form from a point and slope (1=Not yet, 5=Yes confidently), and practice difficulty (1=Too easy, 3=Just right, 5=Too difficult). Ratings never affect academic scoring. Both must be answered before generating the local report PNG. The screenshot layout includes the full questions, selected labels and scale endpoints; PNG export includes the same information with wrapped text. Changing either response invalidates an existing PNG. Back navigation retains responses and date; next-student reset clears responses, report and image. All responses remain memory-only with no transmission or persistence.

Tests cover radio scales/labels/callbacks, congratulations and report navigation, required responses for export, included questions/date/named scores, unchanged grades, stale-PNG invalidation, finishing from the splash, and empty ratings for a subsequent student.

## Faded color guidance and narrated graph sequence

The first problem is fixed for every student: slope 2 through (3,4). Later problems use the nonzero finite slope pool. Problems 1–2 color-code m blue, x₁ green, and y₁ red in the given quantities, general formula, and destination outlines. Coordinate and destination labels remain for all problems. Starting with problem 3, optional Color help defaults off and resets off at each successful step and new problem. The redundant ± keypad key is removed.

The success animation labels the given point and flashes its arrow five times, then does the same for “y-intercept of your answer.” At eight seconds the slope explanation appears as change in y / change in x = signed rise / signed run; unit counting starts afterward. Line drawing and the existing scoring star follow. Reduced motion shows the complete static solution.

## Continue another day

At a checked-problem boundary, Stop & save progress creates a compact resume code and a named/dated downloadable card. Returning students enter their name, original hour and code on the start screen. See [resume-codes.md](resume-codes.md) for restored fields, initial/hour checks, local-only handling and tests.

## Aligned givens and repeated slope counting

The practice layout puts the blue given-values panel and the algebra work in the same left column. Given slope/point headings share a baseline; draggable boxes share their top edge. Name, hour, score, totals, streak and save control occupy the right column above the help/keypad. The problem directions wrap above the blue givens within the left column; the blue panel sits immediately above the algebra work. On narrow phones, identity/scores stack above givens and work.

The success graph now reduces slope to its simplest integer rise/run pair and repeats a run-then-rise staircase from the y-intercept to the given point. Unit labels reset per repetition. Each short line segment draws after its corresponding count; the scoring star starts exactly after the final segment reaches the given point. Moving left reverses both signed counts. The five-flash point callouts and reduced-motion static result remain available. Geometry tests include unreduced fractional slopes and both traversal directions.

The right rail now keeps a compact named scoreboard and Answers/Scratch work controls visible while the left work scrolls. Scratch work replaces the keypad; Back to answers restores it and focuses the current answer field. Ink stays mounted across toggles and steps and clears for the next problem. Stop & save progress is in the scoreboard Menu and remains available only after a checked problem. On phones the tools stack below the work.

A correct final answer awards the star immediately, then holds a 2.8-second rainbow scoreboard glow before the graph solution opens. The glow/star respect reduced motion. From the fifth correct answer onward, the solution has a prominent Skip animation button that advances to the next problem without changing the score.

Easter egg: when the current streak reaches exactly three, after the solution finishes, a two-pose skier drops onto the line, tucks and skis downhill off the clipped graph. A “Nice slope!” speech bubble pops up at landing and travels with the skier. Route direction follows the sign of the slope. Replay repeats the scene; reduced-motion users see the complete static math without the skier. The source skier poses supplied by the teacher were isolated as a transparent sprite sheet using the image tool.

Goat surprise: enabled only when the current streak reaches five (the temporary first-answer test trigger has been removed). Two transparent teacher-supplied goat poses run uphill on the line, stop at the lower of the given point/intercept to bleat, then stop at the higher point to say Steep when |m| ≥ 1 or Not so steep otherwise, before exiting above the graph. The brief cartoon bleat uses local Web Audio synthesis unlocked by checking a correct answer; there is a sound toggle and a visible Baa-a-a caption. Replay resets the sequence; dismissal cancels pending sound. Reduced motion suppresses goat motion and sound. No scoring or storage changes.

Intro buttons and the session Menu use raised base shadows and subtle highlights. Enabled controls depress 3px while pressed, keeping their touch targets and keyboard focus outlines. Disabled controls remain flat. Reduced motion removes transitions.
